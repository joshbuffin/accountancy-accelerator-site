Intro to WebFiling and confirmation statements

Stage 2

Preparation

1

At the start of each month, the accountant reviews the list of confirmation statements coming due within 14 days of the following month, and sends the template email to each client to confirm their details.

Stage 3

Completion

1

Once the client has replied, the accountant reviews whether any changes need to be made.

2

If any edits are needed, the accountant amends the details on the confirmation statement via WebFiling. (If no changes are needed, this step is N/A.)

3

Once any changes have been made, the accountant passes the client's name to whoever files the statement (for example in your team chat).

4

The administrative assistant then files the confirmation statement, drafts an invoice for the £50 Companies House filing fee, marks it as done in the team chat and rolls forward the job card.

🔐 Companies House identity verification: directors and people with significant control (PSCs) must now verify their identity with Companies House and get an 11-character Companies House personal code. When you file the confirmation statement, you must give the identity verification details (personal code) for all current directors, unless they've already been provided. A PSC's personal code isn't given on the confirmation statement; it's provided separately using Companies House's Provide identity verification details for a PSC service ↗.
