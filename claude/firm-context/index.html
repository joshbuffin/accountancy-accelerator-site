Teach Claude about your firm.

This is the first thing to do after installing Claude Code. You fill in a profile of your firm once, paste it into Claude, and Claude turns it into a set of files it reads at the start of every future session.

From then on it already knows your services, pricing, team, clients, tools, tone of voice and rules, so every later prompt (management accounts, sales follow-ups, your website) gets much better answers.

Overview

What this does and what you'll end up with

You give Claude one detailed profile of your firm. Claude reads it and builds these for you, in the folder you're working in:

CLAUDE.md. A master instruction file that Claude loads automatically every time you open it in this folder.

A context folder. Eight short files covering your firm profile, team, services and pricing, clients and delivery, sales and marketing, tools, tone of voice, and rules.

Empty working folders. Clients, templates, SOPs, drafts and projects, ready for the next modules.

A follow-up interview. Claude will ask you about anything you left blank, then summarise your firm back to you and suggest the five most useful things it could help with in the next 30 days.

One-off setup

Set up Claude Code

You only do this once. We use Claude Code through the Claude desktop app. There's no need for VS Code or the terminal.

1

Get a paid plan. Claude Code needs a paid Claude plan (Pro or above). The free plan doesn't include it.

2

Install the app. Download the Claude desktop app for Mac or Windows from claude.ai/download, install it and sign in.

3

Windows only: install Git. Git for Windows is required for the Code tab to run local sessions. Install it from git-scm.com (accept the default options), then close and restart the Claude app. Mac users can skip this.

4

Create a folder. Create a new, empty folder for your firm's AI work, for example Documents > Firm AI. Use this same folder for every prompt in this section.

5

Open it in Claude Code. In the app, click the Code tab. Under the message box, choose Local as the environment. Then use the folder button to pick Open folder… and select your Firm AI folder.

6

Leave permissions on Manual. The default permission mode is called Manual: Claude asks before it creates or edits a file or runs a command, and you click to approve. Leave it on Manual while you're learning. Once you're comfortable, you can switch the mode (under the message box) to Accept edits so you're asked less often.

Node.js comes later. Later prompts (management accounts and your website) also need Node.js, a free program that runs code on your computer. You don't need to install it now: Claude will check and walk you through it when it's needed.

Preparation

Before you start

Set aside the time. You'll need about 45 to 90 minutes to fill in the profile. You don't have to finish in one go.

Have Claude Code ready. Finish the one-off setup above, so the Code tab is open on your Firm AI folder.

Step by step

How to use it

1

Copy the prompt. Press Copy prompt below. It copies everything between the START and END markers. Paste it into a Word or Google Doc.

2

Fill in Part 2. Part 2 is your firm profile. Leave Part 1 exactly as it is: those are Claude's instructions.

3

Paste it into Claude. Paste the whole thing (Part 1 and Part 2) into the message box in the Code tab and press Enter. If the paste is awkward, see "Alternative to pasting" in the tips below.

4

Approve and answer. Claude will ask permission to create files. Say yes. Then answer its follow-up questions, one at a time.

5

Check. Read the summary Claude gives you and correct anything it got wrong. Then check it worked (see "How to check it worked" below).

Good to know

Tips

Detail beats polish. Rough notes and bullet points are fine. Talking through your answers with voice dictation is often the quickest way to get detail in.

Don't know an answer? Leave it blank and Claude will ask you. Write "n/a" if it doesn't apply.

No client data. This is about your firm, not your clients. Don't include client names, UTRs, NI numbers or bank details. Anonymise any examples.

Section 11 matters more than it looks. Your example emails in section 11 are what teach Claude to write like you. Paste real ones with client details removed.

Keep it current. When something changes (a new hire, a price rise, a new service), just tell Claude, for example: "We've raised our minimum fee to £200 a month, update the context." It will update the right file.

Alternative to pasting. Save your completed brief as a plain text file in your Firm AI folder. In Word: File > Save As > Plain Text, named firm-brief.txt. Then type into Claude: "Read firm-brief.txt and follow the instructions in it."

# FIRM SETUP BRIEF FOR CLAUDE CODE

## PART 1: INSTRUCTIONS FOR CLAUDE (do not edit this part)

You are going to become the AI operations partner for my accountancy practice. Everything in Part 2 below is a profile of my firm that I have filled in. Your job in this first session is to turn it into a permanent, well-organised memory of my firm, so that in every future session you already know who we are, how we work and how I want you to help, without me ever having to explain it again.

Please do the following, in order.

STEP 1: READ EVERYTHING FIRST
Read the whole profile before writing anything. Note any sections I have left blank, marked "n/a", or answered vaguely.

STEP 2: CREATE THE FOLDER STRUCTURE
In the current folder, create:
- CLAUDE.md (in the project root): the master instruction file you read at the start of every session.
- A context/ folder containing:
  - firm-profile.md: who we are, regulation, size, stage, goals
  - team.md: people, roles, responsibilities, hours, who does what and who reviews what
  - services-and-pricing.md: every service, what is included, pricing model, minimum fees, out-of-scope work
  - clients-and-delivery.md: ideal client, client journey, onboarding, recurring monthly/quarterly/annual cycle, deadlines, common failure points
  - sales-and-marketing.md: lead sources, sales process, proposals, follow-up, marketing channels, content
  - tools.md: our software stack and what each tool is used for
  - tone-of-voice.md: how we write and speak to clients, with examples
  - rules.md: hard rules, boundaries, compliance and data-handling rules
- Empty folders ready for later work: clients/, templates/, sops/, drafts/, projects/

STEP 3: WRITE THE CONTEXT FILES
Rules for writing them:
- Use clear, structured markdown: headings, bullet points, short paragraphs. These files are for an AI to read quickly and precisely, not marketing copy.
- Use only what I have told you. Never invent facts, figures, names or processes. Where something is missing, write [TODO] with a short note of what is needed.
- Keep my exact wording for anything specific: service names, prices, rules and internal terms.
- Use UK English and UK accounting and tax terminology unless I have said otherwise.
- Do not store client personal data. If I have accidentally included a client's name, UTR, NI number, bank details or similar, leave it out and tell me.

STEP 4: WRITE CLAUDE.md
Keep it short (under about 150 lines) so it loads quickly. It must include:
1. A one-paragraph summary of the firm and your role ("You are the AI operations partner for [firm name]...").
2. The context files as import lines, written exactly like this, so they load automatically in every session:
   @context/firm-profile.md
   @context/team.md
   (and so on for every file in context/)
3. The firm's hard rules, copied from rules.md: the non-negotiables you must always follow.
4. These default working rules, unless I have overridden them in my profile:
   - Ask one question at a time when you need information from me.
   - Never invent information. Ask, or mark it [TODO].
   - Draft, don't send. You never send emails, submit anything to HMRC or Companies House, make payments or publish anything. You prepare drafts for a person to review and action.
   - Connected tools (accounting software, practice management, email and so on) are read-only, unless I explicitly grant write access for a specific tool and a specific task, and that exception is recorded in CLAUDE.md.
   - Professional judgement stays with us. Flag anything technical (tax positions, reliefs, filings, figures going to a client) for review by a qualified team member, and say how confident you are.
   - Check with me before deleting or overwriting any file.
   - Keep client data inside this folder and our approved tools. Never paste it into external websites or services.
   - When I correct you or tell you how I prefer something done, offer to save it to the relevant context file so you remember next time.
5. A short "Keeping this up to date" note: when anything changes (a new team member, a price change, a new service), I can just tell you and you will update the right file.

STEP 5: FILL THE GAPS
Once the files exist, go through every [TODO] and gap. Ask me about them one question at a time, most important first, and update the files as I answer. If I say "skip", leave the [TODO] and move on. Stop after the 10 most important gaps and tell me how many remain, so I can finish the rest another day.

STEP 6: READ IT BACK
Give me:
- A plain-English summary of my firm as you now understand it (around 250 words maximum), so I can sanity-check it.
- Anything that looked inconsistent or contradictory in my answers.
- The 5 highest-value ways you could help my firm in the next 30 days, based specifically on my goals, bottlenecks and time sinks. For each, give a one-line example of what I would type to get started.
- A list of the files you created.

Then ask me whether anything needs changing before we finish.
